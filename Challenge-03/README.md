# Challenge 03 - Online Store Bill calculator

## Problem Statement

A student buys items from an online store. The program reads the purchase amount, customer type, and delivery distance. By using conditional statements, the program calculates the discount and delivery charge and displays the final payable amount.

## Objective

To practice variables, input/output statements, arithmetic operators and conditional statements in C.

## Algorithm

Start

Read the purchase amount.

Read the customer type.

Read the delivery distance.

Based on the customer type and given conditions determine the discount.

Calculate the amount after discount.

Based on given conditions determine the delivery charge.

Calculate the payable amount.

Display the purchase amount, discount, amount after discount, delivery charge and final payable amount.

Stop.
