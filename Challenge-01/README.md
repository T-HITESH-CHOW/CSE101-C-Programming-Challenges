# Challenge 01 - Student Marks Calculator

## Problem Statement

A student has marks for five subjects.Write a c program that reads the marks of all five subjects and calculates the total marks, average marks and percentage of student and displays all three results clearly.

## Objective

The purpose of this programming challenge is to demonstrate the knowledge of variables, data types, input/output statements, operators, and expressions in C.

## Algorithm

1.START

2.READ the marks of five subjects.

3.CALCULATE the total marks.

4.CALCULATE the average marks.

5.CALCULATE percentage of student.

6.DISPLAY total, average, and percentage.

7.STOP.
